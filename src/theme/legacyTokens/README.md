# Legacy-токены

Эти токены сохраняются только для обратной совместимости публичных `lightTheme`,
`darkTheme` и `ThemeType`. Компоненты библиотеки используют `components`,
`semantic` и сгенерированную структуру `fonts`.

Единственная точка подключения legacy-токенов — `index.ts`. Компоненты не должны
импортировать отдельные файлы из этой директории. Удалить этот слой можно в
следующей мажорной версии.

К этому же слою относятся deprecated-алиасы `fonts.primary` и `fonts.secondary`,
а также их преобразование в `fonts.fontFamily.heading` и
`fonts.fontFamily.base`.
