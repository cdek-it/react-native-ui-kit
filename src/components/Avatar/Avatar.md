# Avatar

Аватар пользователя с изображением, SVG-иконкой или текстом и необязательным
бейджем.

## Использование

```tsx
import { Avatar, Badge } from '@cdek-it/react-native-ui-kit'

export function UserAvatar() {
  return (
    <Avatar
      accessibilityLabel='Иван Иванов, 3 уведомления'
      badge={<Badge severity='danger'>3</Badge>}
      type='label'
    >
      ИИ
    </Avatar>
  )
}
```

## Props

- `type` — обязательный вариант содержимого: `label | icon | image`. Определяет
  доступные props:
  - `label` — обязательная строка `children`. Текст отображается в верхнем
    регистре, в одну строку; при нехватке места обрезается без многоточия.
    Инициалы из имени автоматически не формируются
  - `icon` — обязательная SVG-иконка `Icon` типа `SvgSource`; встроенной иконки
    по умолчанию нет. `iconColor` задаёт её цвет, по умолчанию используется цвет
    Avatar из текущей темы
  - `image` — `source` типа `ImageSourcePropType`. Изображение заполняет аватар
    с обрезкой по краям (`cover`). `onError` вызывается при ошибке загрузки;
    автоматической замены на текст или иконку нет — её задаёт потребитель
- `size` — размер: `base`, `large`, `xlarge`; по умолчанию `base`. Число задаёт
  одинаковые ширину и высоту. Устаревший `normal` соответствует `base`
- `shape` — форма: `circle | square`; по умолчанию `circle`. У `square`
  скруглённые углы
- `badge` — содержимое бейджа в правом верхнем углу. Передавайте условно: `null`
  или `undefined` скрывают бейдж. Устаревший `showBadge={false}` также скрывает
  переданный бейдж; без `badge` этот prop недоступен
- `style` — стили внутреннего визуального контейнера, а не внешнего контейнера и
  не бейджа. Размер задавайте через `size`

Полный контракт — [AvatarProps и AvatarSize](./Avatar.tsx).

## Доступность

Для самостоятельного значимого Avatar задавайте `accessibilityLabel` или
`aria-label`: скринридер воспринимает его как одно изображение с ролью `image`.
`accessibilityLabel` имеет приоритет, в том числе если передана пустая строка.
Без непустого имени Avatar скрыт от скринридера; текст и изображение не создают
имя автоматически. Явное скрытие через accessibility props сохраняется и при
заданном имени.

Визуальное содержимое и `badge` отдельно не озвучиваются. Если бейдж передаёт
значимый статус или количество, включите этот смысл в доступное имя Avatar или
его интерактивного родителя.

Для обработки нажатия используйте интерактивного родителя, например `Pressable`.
Доступное имя, роль и состояние задавайте родителю, оставляя Avatar без
собственного имени. Сам Avatar не обрабатывает нажатия.

Текст не масштабируется с системным размером шрифта.
