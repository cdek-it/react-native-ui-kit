# ProgressSpinner

Индикатор ожидания без определённого прогресса. Отображается, пока компонент
смонтирован; после завершения загрузки замените его содержимым.

## Использование

```tsx
import { ProgressSpinner } from '@cdek-it/react-native-ui-kit'

export function OrdersLoading() {
  return (
    <ProgressSpinner
      accessibilityLabel='Загрузка заказов'
      size='base'
      fill='primary'
    />
  )
}
```

## Props

Все props необязательные.

- `size` — размер: `small` — 16 × 16, `base` — 32 × 32, `large` — 48 × 48,
  `xlarge` — 56 × 56. По умолчанию `base`. Размеры берутся из токенов темы
  `components.progressspinner.extend`: `small`, `medium` (для `base`), `large`,
  `xlarge`.
- `fill` — цвет: `primary` или `white`. По умолчанию `primary`. Цвета берутся из
  темы; для `white` используйте контрастный фон.
- `testID` — идентификатор для тестов. По умолчанию `ProgressSpinner`.

Поддерживаются атрибуты `AccessibilityProps` React Native. Остальные нативные
props View и SVG, включая `style`, обработчики событий и `children`, не входят в
публичный контракт. Публичный `ref` не поддерживается. Props значения прогресса
и callback завершения нет: жизненным циклом загрузки управляет потребитель.

Полный контракт — [ProgressSpinnerProps](./ProgressSpinner.tsx).

### Устаревшие размеры

`sm`, `md`, `lg`, `xl` пока поддерживаются как соответствия `small`, `base`,
`large`, `xlarge`. Используйте полные имена в новом коде. Сокращения помечены
устаревшими и запланированы к удалению в 2.0.

## Доступность

По умолчанию корневой SVG доступен: `accessible={true}`,
`accessibilityRole='progressbar'`. Доступное имя автоматически не задаётся;
передавайте `accessibilityLabel`, описывающий загрузку. При необходимости можно
задать `accessibilityHint`. `accessible` и `accessibilityRole` можно
переопределить.

`accessibilityState.busy` всегда `true`, даже при переданном `busy: false`.
Остальные поля `accessibilityState` сохраняются. После загрузки уберите
индикатор, а не пытайтесь сбросить его `busy`.

Внутри кнопки или другого доступного контейнера передайте спиннеру
`accessible={false}`, чтобы избежать отдельного объявления индикатора. Доступное
имя, роль и состояние загрузки в таком случае задавайте родителю.

При включённом системном Reduce Motion вместо анимации отображается статичная
полуокружность. Компонент отслеживает изменение этой настройки; до получения
начального ответа системы анимация включена.
