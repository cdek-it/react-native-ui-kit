# Message

Сообщение внутри экрана с цветной шапкой и необязательной полосой таймера.

## Использование

```tsx
import { Message } from '@cdek-it/react-native-ui-kit'
;<Message
  title='Проверьте данные получателя'
  caption='Для доставки нужен действующий номер телефона.'
  severity='warning'
  onClose={hideMessage}
/>
```

## Props

- `title` — обязательный заголовок в шапке. Максимум две строки, далее
  многоточие.
- `caption` — подпись в нижней секции.
- `body`, `footer` — независимые `ReactNode`. Отображаются при наличии ноды.
- `severity` — `info | success | warning | danger`. По умолчанию `info`.
- `Icon` — пользовательская SVG-иконка вместо стандартной для severity.
- `hiddenIcon` — скрывает иконку. По умолчанию `false`.
- `onClose` — показывает кнопку закрытия и вызывается без аргументов. Удалением
  сообщения управляет потребитель.
- `closeLabel` — текст действия вместо крестика.
- `closeAccessibilityLabel` — необязательное доступное имя крестика.
- `timerValue` — длительность в секундах. Полоса внизу показывает оставшееся
  время, иконка остаётся в шапке. Без значения или при `0` таймер отсутствует.
- `onTimerFinish` — вызывается один раз после завершения отсчёта. Сообщение
  остаётся видимым. Изменение длительности перезапускает отсчёт.

Ширина задаётся через `style`. Полный контракт — [MessageProps](./types.ts).

## Доступность

Тексты и вложенные действия доступны отдельно. Декоративная иконка и полоса
таймера отдельно не озвучиваются. Крестик имеет имя «Закрыть», которое можно
переопределить через `closeAccessibilityLabel`. Текстовое действие озвучивается
по видимому `closeLabel`. Автоматическое объявление выполняет контейнер показа.

## Миграция

Прежний компонент доступен через
`import { Message } from '@cdek-it/react-native-ui-kit/legacy'`. Для содержимого
всплывающих уведомлений используйте [ToastMessage](./ToastMessage.md).
