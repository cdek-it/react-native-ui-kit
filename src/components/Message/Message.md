# Message

Сообщение со статусом, подписью, произвольным содержимым и действиями.

## Использование

```tsx
import { Message } from '@cdek-it/react-native-ui-kit'
;<Message
  title='Заказ создан'
  caption='Мы сообщим, когда он будет готов к отправке'
  severity='success'
  onClose={() => setMessageVisible(false)}
/>
```

## Props

- `title` — заголовок без ограничения числа строк
- `caption` — подпись под заголовком
- `body`, `footer` — независимые `ReactNode`, отображаются по наличию
  содержимого
- `severity` — `info` по умолчанию, `success`, `warning` или `danger`
- `Icon` — пользовательская SVG-иконка. Штатные иконки: info-circle,
  circle-check, alert-triangle и alert-circle соответственно severity
- `hiddenIcon` — скрывает иконку, включая пользовательскую, но не работающий
  таймер
- `onClose` — показывает закрытие и вызывается без аргументов. Видимостью
  управляет потребитель
- `closeLabel` — текст кнопки закрытия. Без текста показывается крестик
- `timerValue` — положительная длительность в секундах. Круговой числовой таймер
  заменяет иконку, `0` или отсутствие значения выключает его
- `onTimerFinish` — вызывается однократно по окончании отсчёта. Сообщение
  остаётся видимым. Изменение длительности перезапускает отсчёт, смена callback
  — нет

Ширина задаётся через `style`, высота зависит от содержимого.

Контракт: [MessageProps](./Message.tsx)

## Доступность

Корень по умолчанию не объединяет содержимое в один accessibility-элемент.
Действия в `body`, `footer` и закрытие доступны отдельно. Декоративная иконка и
таймер отдельно не озвучиваются.

Имя текстового закрытия берётся из `closeLabel`. Для крестика используется
необязательный `closeAccessibilityLabel` либо «Закрыть».

Если сообщение нужно автоматически объявлять при появлении, обеспечьте это в
контейнере показа. Доступность у сообщений с таймером стоит дополнительно
продумать.
