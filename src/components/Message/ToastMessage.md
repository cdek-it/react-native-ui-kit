# ToastMessage

Содержимое всплывающего уведомления с цветной полосой слева и тенью.

## Использование

```tsx
import { ToastMessage } from '@cdek-it/react-native-ui-kit'
;<ToastMessage
  title='Заказ скрыт'
  severity='success'
  timerValue={5}
  closeLabel='Отменить'
  onClose={restoreOrder}
  onTimerFinish={hideToast}
/>
```

## Props

- `title` — обязательный заголовок, `caption` — необязательная подпись.
- `body`, `footer` — независимые `ReactNode`, отображаются при наличии ноды.
- `severity` — `info | success | warning | danger`. По умолчанию `info`.
- `Icon` — пользовательская SVG-иконка вместо стандартной для severity.
- `hiddenIcon` — скрывает иконку. По умолчанию `false`, на таймер не влияет.
- `onClose` — показывает закрытие и вызывается без аргументов.
- `closeLabel` — текстовое действие вместо крестика.
- `closeAccessibilityLabel` — необязательное доступное имя крестика.
- `timerValue` — длительность в секундах. Числовой таймер заменяет иконку. Без
  значения или при `0` таймер отсутствует.
- `onTimerFinish` — вызывается один раз после завершения отсчёта. Изменение
  длительности перезапускает отсчёт.

Компонент самостоятельно не скрывается. Показ поверх экрана, позиции, очередь,
свайпы, анимации появления и удаление обеспечивает контейнер приложения. Ширина
задаётся через `style`. Полный контракт — [ToastMessageProps](./types.ts).

## Доступность

Тексты и вложенные действия доступны отдельно. Иконка и визуальный таймер
отдельно не озвучиваются. Крестик имеет имя «Закрыть», которое можно
переопределить через `closeAccessibilityLabel`. Имя текстового действия берётся
из `closeLabel`. Объявление при появлении выполняет контейнер показа.

## Миграция

Сначала сохраните старое оформление, заменив импорт Message на
`@cdek-it/react-native-ui-kit/legacy`. Затем замените содержимое тостов на
`ToastMessage`, сохранив существующий механизм показа и callbacks. Для
встроенных сообщений используйте [Message](./Message.md).
